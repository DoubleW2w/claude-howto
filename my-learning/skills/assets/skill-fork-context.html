为什么用 fork

复杂 skill 在 隔离的上下文窗口 里跑——无论它读多少文件、调多少工具， 那些中间 token 都留在右侧。主对话只收到 一份回传的最终结果， 通过 dispatch → execute → return 三步，窗口始终干净。
