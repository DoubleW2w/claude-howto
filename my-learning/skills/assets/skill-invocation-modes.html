Skills 调用控制三模式

frontmatter 中的两个开关决定「谁能触发这个 skill」——你（/name）和 Claude（自动）。三种组合覆盖三种场景。

模式 01 · 默认
无 frontmatter 开关
示例 skill: code-review
FRONTMATTER
---
name: code-review
description: Review the diff
---
无 disable-model-invocation · 无 user-invocable
👤
你键入 /code-review
✓
🤖
Claude自动判断需要时调用
✓
何时用
通用——大多数 skill。既可手动触发，也可让 Claude 在合适的时机自动调用。
模式 02 · 禁止自动调用
disable-model-invocation: true
示例 skill: deploy
FRONTMATTER
---
name: deploy
description: Ship to prod
disable-model-invocation: true
---
👤
你显式键入 /deploy
✓
🤖
Claude不能擅自部署
✗
何时用
有副作用的 workflow——/commit、/deploy、/send-slack-message。不让 Claude 因为「看起来就绪」就擅自执行不可逆动作。
模式 03 · 对用户隐藏
user-invocable: false
示例 skill: legacy-system-context
FRONTMATTER
---
name: legacy-system-context
description: Old system lore
user-invocable: false
---
👤
你无法手动调用
✗
🤖
Claude需要时自动加载
✓
何时用
背景知识——如解释旧系统的内部约定。对 Claude 有用，但对用户不是一个「有意义的动作」。
核心权衡

默认 谁都行 · 禁止自动调用 只留人工确认 · 隐藏用户入口 只留给 Claude——选择取决于「这个动作能不能被信任地自动执行」。
