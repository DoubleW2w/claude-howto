## 适用范围

本规范适用于项目中所有带数字前缀的课程模块（如 `XX-模块名/`）及其对应的 `zh/XX-模块名/` 翻译目录。无论模块数量如何增减，翻译时均遵循本规范。

本文档中出现的具体模块名仅为**示例**，用于说明规则的实际应用方式。

同时参考 [LOCALIZATION-STYLE.md](LOCALIZATION-STYLE.md)

---

## 基本原则

1. **忠实原文** — 翻译内容必须与英文版一一对应，不遗漏章节、段落或条目
2. **不猜测不补充** — 不添加英文版没有的内容，不推断未写的意图
3. **自然中文** — 保留英文原汁原味，但用符合中文阅读习惯的方式表达
4. **结构对齐** — 标题层级、章节顺序、列表结构必须与英文版一致

## Markdown 语法保留

翻译时必须原样保留以下 Markdown 语法结构：

### 格式标记

| 标记 | 规则 | 示例 |
|------|------|------|
| 反引号 `` ` `` | 包裹代码/命令时保留 | `/init`、`CLAUDE.md` |
| 粗体 `**...**` | 包裹关键术语时保留 | **Managed Policy** |
| 斜体 `*...*` | 包裹术语首次出现时保留 | *frontmatter* |
| 删除线 `~~...~~` | 标记废弃内容时保留 | ~~快速单行添加~~ |
| 链接 `[text](url)` | 保留语法，翻译显示文字 | [官方文档](https://...) |

### 代码块

- 语言标签保留：`bash`、`json`、`python`、`markdown` 等
- 代码内容不翻译
- 代码块内注释可翻译为中文

### Mermaid 图

- 图表结构和语法保持原样
- 节点标签中的说明文字翻译为中文
- `style` 指令保持原样
- 箭头标签（`|text|`）翻译为中文

### 示例

英文原文：
```
| **Purpose** | Edit existing memory files | Initialize new CLAUDE.md |
```

中文翻译：
```
| **用途** | 编辑已有 memory 文件 | 初始化新的 CLAUDE.md |
```

## 资源文件处理

### 图片资源

1. **复制资源文件** — 英文目录中的图片必须复制到对应的中文目录
2. **同目录引用** — 图片引用保持同目录相对路径（文件名即可）

示例（以 `02-memory` 为例，其他模块同理）：

```
英文目录结构：
02-memory/
├── README.md          → 引用 memory-ask-claude.png
└── memory-ask-claude.png

中文目录结构：
zh/02-memory/
├── README.md          → 引用 memory-ask-claude.png（同目录）
└── memory-ask-claude.png（从英文目录复制）
```

### Logo 等共享资源

Logo 等位于 `resources/` 目录的共享资源不复制到 `zh/`，通过修正相对路径引用：

```
英文版（如 XX-module/README.md）：
srcset="../resources/logos/claude-howto-logo-dark.svg"

中文版（zh/XX-module/README.md）：
srcset="../../resources/logos/claude-howto-logo-dark.svg"
```

## 路径修正规则

中文目录 `zh/` 比英文目录多一层嵌套，所有相对路径需要相应调整。

### 规则

| 英文版路径 | 中文版路径 | 规则 |
|-----------|-----------|------|
| `../resources/` | `../../resources/` | 向上到项目根，多走一层 |
| `../05-mcp/` | `../05-mcp/` | 兄弟模块不变（都在 `zh/` 下） |
| `example.png` | `example.png` | 同目录引用不变 |
| `@docs/architecture.md` | `@docs/architecture.md` | 同项目内导入不变 |

### 计算方法

```
通用规则：
英文路径：<module>/README.md → resources/ = ../resources/
中文路径：zh/<module>/README.md → resources/ = ../../resources/

结论：从 zh/ 子目录到项目根资源，比英文版多一个 ../
```

### 跨模块链接

模块间链接不需要调整——`zh/01-slash-commands/`、`zh/02-memory/` 等都在同一层级 `zh/` 下，互为兄弟目录。

## 排版细节

### 标点符号

- 中文正文使用中文标点：`，`、`。`、`：`、`（`、`）`
- 代码块和行内代码中保持英文标点
- 括号内为英文内容时用英文括号：`(v2.1.83+)`

### 连接符

| 场景 | 英文 | 中文 |
|------|------|------|
| 破折号 | ` - ` | ` — `（em dash） |
| 列表分隔 | ` - ` | `：`（冒号）或 ` — ` |
| 版本号 | `v2.1.83+` | `v2.1.83+`（不翻译） |

### 列表格式

英文版用 `- ` 的说明性列表，中文版根据上下文选择：

```
英文：
- **Managed Policy** - Company-wide policies

中文：
- **Managed Policy** — 组织级策略（用 em dash）
```

### 元数据页脚

```
英文：
**Last Updated**: May 25, 2026

中文：
**最后更新**：2026 年 5 月 25 日（日期格式转为中文习惯）
```

## 翻译检查清单

翻译完成后，逐项验证：

- [ ] **章节对齐** — 中英文标题层级和数量一致
- [ ] **无遗漏** — 英文版每个段落、列表项、表格行都有对应翻译
- [ ] **无添加** — 没有英文版中不存在的内容
- [ ] **专有名词** — Claude Code、CLAUDE.md 等未翻译
- [ ] **代码完整** — 所有代码块、行内代码保持原文
- [ ] **Markdown 语法** — 反引号、粗体、删除线等标记保留
- [ ] **Mermaid 图** — 图表语法正确，标签已翻译
- [ ] **资源文件** — 图片已复制到中文目录
- [ ] **路径正确** — 相对路径已根据目录层级调整
- [ ] **链接有效** — 所有内部链接和外部 URL 可访问
- [ ] **排版一致** — 标点符号、连接符使用统一
- [ ] **代码块注释** — 代码块中的注释已翻译（如适用）
