Skill 类型优先级覆盖链

同名 skill 在不同位置同时存在时，高优先级位置胜出：enterprise > personal > project。Plugin 因命名空间隔离，从不参与这场冲突。

为什么 Plugin 独立

前三者比的是 同名——一旦企业版定义了 code-review，个人和项目的同名版就被压制。Plugin 走的是 plugin-name:skill-name 命名空间，名字根本不同，所以它和覆盖链各自独立、互不相争。
